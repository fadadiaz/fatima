# fatima.com.ar

Portfolio de Fátima Díaz, diseñadora gráfica y web en Buenos Aires. Reúne proyectos de identidad visual, diseño web, diseño editorial y herramientas digitales.

## Stack

- [Astro](https://astro.build) 6, Node 22.12 o superior
- Proyectos como colección de contenido en `src/content/proyectos/` (`.md` o `.mdx`)
- Imágenes de proyectos en `src/assets/proyectos/<carpeta>/`, optimizadas por Astro en el build
- Sitemap con `@astrojs/sitemap` y MDX con `@astrojs/mdx`

## Comandos

| Comando           | Acción                                        |
| :---------------- | :-------------------------------------------- |
| `npm install`     | Instala las dependencias                      |
| `npm run dev`     | Servidor local en `localhost:4321`            |
| `npm run build`   | Genera el sitio en `./dist/`                  |
| `npm run preview` | Muestra el sitio generado antes de publicarlo |
